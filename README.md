# Personal Finance Service

Учебный серверный проект на FastAPI для учёта личных доходов, расходов, счетов, категорий, бюджетов и тегов.

## Запуск

1. Создать виртуальное окружение: `python -m venv .venv`.
2. Активировать его в PowerShell: `.venv\Scripts\Activate.ps1`.
3. Установить зависимости: `pip install -r requirements.txt`.
4. Запустить сервер: `uvicorn app.main:app --reload`.

Документация API после запуска доступна по адресу `http://127.0.0.1:8000/docs`.
