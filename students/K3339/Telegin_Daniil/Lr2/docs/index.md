# Лабораторная работа 2

В работе сопоставляются потоки, процессы и асинхронность в Python на задачах
двух типов:

1. CPU-bound вычисление суммы чисел.
2. I/O-bound загрузка веб-страниц и сохранение данных в PostgreSQL.

Полное описание реализации, порядок запуска и результаты экспериментов приведены
в разделе [«Лабораторная работа 2»](lr2.md).
